# Rev.9 IMU小基板：Cタイプ配線（配置はRev.8から変更なし）

対象はAdafruit MPU6050 #3886と、秋月のCタイプ72×47 mm・2.54 mmピッチ基板を1枚ずつ使う構成。IMU1とIMU2は同じ部品配置・裏面配線で、アドレスジャンパーだけが異なる。

## 部品配置（部品面から見た座標）

|部品|穴位置・向き|
|---|---|
|MPU用1×6Pロングピンソケット|行8、列10〜15。左からVIN / 3Vo / GND / SCL / SDA / INT|
|100nF積層セラミック|IMU1=C4、IMU2=C5。行10、列10=3V3、列12=GND|
|電源2P端子台|行14、列10=3V3、列11=GND。挿入口は基板下辺側|
|信号2P端子台|行14、列13=SCL、列14=SDA。挿入口は基板下辺側|

`3Vo`はモジュールのレギュレーター出力なので未接続にする。`INT`も今回の回路では使わない。

## 裏面配線

|No.|ネット|始点|経路・はんだ点|終点|
|---:|---|---|---|---|
|1|3V3 / VIN|(10,8)|(10,10)でC4/C5脚を接続|(10,14)|
|2|GND|(12,8)|(12,10)でC4/C5脚、(12,12)で固定|(12,12)|
|3|GND|(12,12)|短い横線|(11,12)|
|4|GND|(11,12)|直線|(11,14)|
|5|SCL|(13,8)|直線|(13,14)|
|6|SDA|(14,8)|直線|(14,14)|

この配置は4ネットの配線が交差しない。0.5 mmスズメッキ線を裏面ランドに沿わせ、端点・分岐・曲がり点をはんだ付けする。コンデンサーは3V3とGNDの間に入る部品であり、両端をワイヤーで直結しない。

## メイン基板との4芯ケーブル

|色|メイン基板側|IMU小基板側|
|---|---|---|
|赤|3V3|3V3（MPU VINへ）|
|黒|GND|GND|
|緑|SDA|SDA|
|青|SCL|SCL|

小基板の信号端子は左からSCL/SDA、メイン基板はSDA/SCLなので、端子の位置ではなくラベルと色で接続する。外部ケーブルはAWG24より線を使い、2本ずつ電源端子台・信号端子台へ入れる。ケース出口でケーブルを固定し、端子台へ引張荷重を掛けない。

## アドレス

- IMU1：裏面ADDRジャンパーを開放したまま。既定の0x68。AD0追加配線は不要。
- IMU2：裏面ADDRジャンパーの2パッドをはんだで短絡。0x69。AD0をGNDへつながない。

## MPU基板の固定

1×6Pソケットだけでも電気的には保持できるが、ペダル周辺の振動を考えて上側の取付穴2個も固定する。MPU基板をソケットへ仮挿ししてC基板へ現物写しし、図の赤破線位置付近へ約2.7 mmの穴を2個あけ、M2.5ナイロンねじ・スペーサーで固定する。モジュールの公式基板データでは取付穴径が2.5 mmで、上側穴は2.54 mmピッチ穴の中間に来るため、既存穴へ無理に合わせない。穴加工時は部品を外し、ガラスエポキシ粉じんを吸い込まないように処理する。

## 組立てと確認

1. 通電せず、C基板・ソケット・MPU・端子台を仮置きする。
2. 1×6Pソケット、端子台、C4/C5をはんだ付けする。
3. 裏面の6区間を配線する。
4. MPUを挿す前に、3V3―GNDが短絡していないこと、各端子から対応ソケットピンまで導通することをテスターで確認する。
5. IMU2だけADDRジャンパーを閉じる。IMU1は開放を維持する。
6. MPUを挿し、3.3 Vを給電してI²Cスキャンで0x68と0x69を確認する。

設計上、4ネットの接続点は互いに重ならず、ソケットの3Vo/INTは未接続、C4/C5はVIN―GND間にのみ入る。穴範囲は25列×15行内で、MPU外形25.4×17.78 mmと2P端子台の配置もC基板72×47 mm内に収まる。実物の互換MPU基板はピン配置や外形が異なることがあるため、#3886以外を使う場合はこの図をそのまま使わず型番を照合する。
