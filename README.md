# 2組のハンドル・ペダル入力

ESP32 1台でMPU6050 2台とペダル2台を読み取り、USBシリアル（115200 baud）へ出力します。
ペダルにはADS1115 1台の2チャンネルを使用します。

## 配線

| 接続先 | SDA | SCL | I2Cアドレス |
| --- | --- | --- | --- |
| ハンドル1のMPU6050 | GPIO21 | GPIO22 | 0x68（AD0をGNDへ） |
| ADS1115 | GPIO21 | GPIO22 | 0x48（ADDRをGNDへ） |
| ハンドル2のMPU6050 | GPIO21 | GPIO22 | 0x69（AD0を3.3Vへ） |

- ペダル1のアナログ出力 → ADS1115 A0
- ペダル2のアナログ出力 → ADS1115 A1
- ESP32・IMU・ADS1115・ペダルのGNDを共通にする。
- I2Cは3.3Vロジックを使用する。ペダル入力は0〜3.3Vを想定。

全機器のSDA・SCLをGPIO21・GPIO22にそれぞれ共通接続します。
ハンドルのアドレスは固定し、切断時にももう一方のIMUへ切り替えません。
この構成はMPU6050専用です。MPU9250/9255は初期化前に拒否します。
ピン番号は `src/main.cpp` の定数で変更できます。

## 出力

1行に2組の入力をCSVで出力します。

```text
pedal1,handle1_deg,pedal2,handle2_deg
0.25,-30.50,0.80,45.20
```

ペダルは0.00〜1.00、ハンドル角度は度単位の累積回転角です。
従来の2列から4列へ変更したため、受信側も4列を読み取るように変更してください。
初期化などのメッセージは `[` で始まるので、受信側では読み飛ばしてください。
未接続またはフィルタ収束待ちの入力には `nan` を出力します。
I2Cの読み取りは順番に行うため、厳密に同一時刻のサンプリングではありません。

## 起動と操作

起動時はハンドル1、2の順に個別にキャリブレーションします。
シリアルの案内に従い、ジャイロの校正中は対象のIMUを静止させてください。
その後、両方のフィルタを約5秒間収束させます。
角度0はIMUのY軸が水平で-X軸が重力方向を向く姿勢です。回転軸はZ軸です。

- `z` / `Z`：両ハンドルの累積回転追跡を再開始（重力によるゼロ基準は固定）。
- `b`：両フィルタのbetaを0.05増加。
- `B`：両フィルタのbetaを0.05減少。

切断された機器は約1秒間隔で同じアドレスへの再接続を試みます。
共通バスのSDA/SCLが故障機器によって固定された場合は、全入力に影響します。
校正済みのハンドルは再校正せず、約1.2秒間フィルタを再収束させます。
起動時に未接続だったIMUを初めて接続した場合は校正が必要になり、
その校正中は全体のシリアル出力が一時停止します。

## ビルド

```sh
pio run
```
